# Hikaye Evreni (Story Universe)

**Hikaye Evreni** is a high-performance, full-stack community platform designed for storytellers and readers. It offers a clean, user-friendly interface for authors to publish their work and for readers to discover new narratives.

This project showcases a robust architecture built using a modern and scalable technology stack.

## 🛠️ Technology Stack

The project is built with a focus on performance, scalability, and clean code.

* **Frontend:** [React](https://reactjs.org/) with [Tailwind CSS](https://tailwindcss.com/) for a modern UI and [Redux Toolkit](https://redux-toolkit.js.org/) for state management.
* **Backend:** [FastAPI](https://fastapi.tiangolo.com/) (Python) providing high-performance asynchronous API endpoints.
* **Database:** [PostgreSQL](https://www.postgresql.org/) for reliable relational data storage.
* **Cache:** [Redis](https://redis.io/) for ultra-fast data retrieval and performance optimization.
* **Containerization:** [Docker](https://www.docker.com/) for consistent environment management and deployment.

## 🚀 Key Features

* **Story Creation:** Authors can easily create and "seal" their stories with metadata like title, category, and summary.
* **Immersive Discovery:** A "Discover" module that allows users to filter through various genres.
* **User Profiles:** Personalized dashboards for authors to interact with their followers.
* **Secure Auth:** Multi-provider login support (Email, Google, Apple).

## 🔧 How to Run

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/yourusername/hikaye-evreni.git](https://github.com/yourusername/hikaye-evreni.git)
    ```
2.  **Start the environment with Docker:**
    ```bash
    docker-compose up --build
    ```
3.  **Access the application:**
    * Frontend: `http://localhost:3000`
    * Backend API: `http://localhost:8000`
